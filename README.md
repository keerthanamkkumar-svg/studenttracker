# 📚 Student Task & Deadline Manager

A simple and user-friendly web application designed to help students organize their academic tasks, manage assignment deadlines, and track their daily progress.

## 🌟 About the Project

Students often have multiple assignments, records, projects, and other academic activities to complete. Managing all these activities manually can sometimes lead to missed deadlines and incomplete work.

To solve this problem, I developed the Student Task & Deadline Manager.

This application allows students to add their academic tasks, set submission dates, track completed tasks, and manage pending work in one place.

This is my first web development project, developed as a beginner-friendly practical application to solve a real-life student problem.

## 🎯 Problem Statement

Students frequently face difficulties in managing multiple academic activities and remembering their submission deadlines.

Using traditional methods such as notebooks or manually written reminders can make task management difficult.

Therefore, a simple digital platform is needed to organize academic tasks and track their completion status.

## 💡 Project Objective

The main objective of this project is to develop a simple task management application that helps students:

- Organize their academic activities.
- Remember assignment submission dates.
- Track pending and completed tasks.
- Improve time management.
- Reduce the chances of missing deadlines.

## ✨ Features

1. **Add Tasks**
   - Enter assignment or activity names.
   - Add tasks easily using the Add Task button.

2. **Set Deadlines**
   - Select the submission date for each task.

3. **View Tasks**
   - Display all added tasks in one place.

4. **Mark as Completed**
   - Mark tasks as completed after finishing them.

5. **Delete Tasks**
   - Remove unnecessary tasks from the list.

6. **Local Data Storage**
   - Save task information using browser LocalStorage.
   - Retain saved tasks after refreshing the page in the same browser.

## 🖥️ Application Workflow

1. Open the Student Task Manager website.
2. Enter the name of your assignment or task.
3. Select its submission deadline.
4. Click the Add Task button.
5. View the task in your task list.
6. Mark the task as completed when finished.
7. Delete tasks that are no longer required.
